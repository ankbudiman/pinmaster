# Pin Master web files (GitHub Pages)

Files in this zip (keep the folder layout):
`index.html`, `login.html`, `hub.html`, `tournament.html`, `users.html`, `setup.html`, `pm.css`, `pm.js`, `config.js`, `support.js`, and the folder `vendor/` (`react.js`, `react-dom.js`).

New in this version: `hub.html` (Tournament Hub) and `tournament.html` (one tournament's dashboard).

## Update the existing site (about 5 minutes)
1. Unzip the file on your computer.
2. Open your repository `ankbudiman/pinmaster` on github.com and click **Add file > Upload files**.
3. Drag in everything from the unzipped folder, including `vendor`. Say yes to replacing files with the same name.
4. Click **Commit changes**. Wait a minute or two, then open `https://ankbudiman.github.io/pinmaster/`.

`config.js` already holds your web app link. Do not change it.

## Check it
1. Sign in as an admin. You land on the Tournament Hub.
2. Click a tournament's name or Dashboard. You see its dashboard with module tiles.
3. Click Tournament Setup. Setup opens that tournament. Hub, Dashboard and Users links are in its top bar.
